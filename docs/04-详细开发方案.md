## 1. 产品定义

- **产品名（暂定）**：切片工作台（SliceStudio）
- **形态**：Web 工作台优先（Docker/本机部署），桌面壳后置；CLI 与 MCP 与 Web 共用同一管线
- **目标用户**：切片分销团队/MCN（主）、主播本人（次）
- **核心循环**：素材入库 → AI 转写+信号+选段（出候选）→ **人工审核/精修（clips0→clips1）** → 钩子工坊 → 成片/剪映草稿 → 合规检查 → 发布包 → 数据回流
- **不可违背的产品原则**：
  1. AI 只出候选，人显式确认才进成片；任何自动链路都有审核闸门
  2. 不做死按钮：当前环境不可用的引擎/选项不展示或置灰+原因
  3. 长任务必须有实时数字进度（阶段+计数+百分比）
  4. 每一刀可审计：切点理由、改动记录、降级记录全部落回执
  5. 源素材永不修改，产物全部进工作目录

## 4. 数据模型（DDL 草案；P0 落 SQLite：UUID→TEXT、JSONB→JSON、TIMESTAMPTZ→TIMESTAMP，语义不变）

```sql
-- 素材
CREATE TABLE material (
  id UUID PRIMARY KEY,
  source_type TEXT NOT NULL,          -- local_file | url | m3u8 | recorded
  source_uri TEXT NOT NULL,
  file_path TEXT,                     -- 落盘后本地路径
  fingerprint TEXT NOT NULL,          -- sha256(前16MB+大小+时长)，缓存键成分
  duration_ms BIGINT, width INT, height INT, fps REAL,
  danmaku_path TEXT,                  -- 录播姬xml/抖音jsonl，可空
  license_id UUID,                    -- 授权台账外键，可空（自有素材）
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 授权台账
CREATE TABLE license (
  id UUID PRIMARY KEY,
  licensor TEXT NOT NULL,             -- 主播/MCN
  scope JSONB NOT NULL,               -- 素材范围/账号/期限/可否投流/可否改编
  proof_path TEXT,                    -- 书面授权文件
  expires_at DATE,
  notes TEXT
);

-- 转写缓存（跨机续跑核心）
CREATE TABLE transcript (
  id UUID PRIMARY KEY,
  material_id UUID REFERENCES material(id),
  cache_key TEXT UNIQUE NOT NULL,     -- fingerprint|engine|model|params_hash
  engine TEXT, model TEXT,
  words JSONB NOT NULL,               -- [{w,start_ms,end_ms,spk?}]
  sentences JSONB NOT NULL,           -- [{text,start_ms,end_ms,spk?}]
  hotwords JSONB,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 剪辑项目
CREATE TABLE project (
  id UUID PRIMARY KEY,
  material_id UUID REFERENCES material(id),
  name TEXT NOT NULL,
  live_type TEXT NOT NULL,            -- ecommerce|entertainment|knowledge|game|talent
  intent TEXT,                        -- user-intent 自然语言定向
  background TEXT,                    -- 主播/术语/账号定位背景
  prompt_id UUID,                     -- 系统提示词资源
  profile TEXT NOT NULL,              -- cpu-cloud | gpu-local（快照）
  status TEXT NOT NULL,               -- 见 §7 状态机
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 候选区间：AI 粗选与人工精修分离（产品理念的数据化）
CREATE TABLE clip_candidate (
  id UUID PRIMARY KEY,
  project_id UUID REFERENCES project(id),
  layer TEXT NOT NULL CHECK (layer IN ('clips0','clips1')),
  parent_id UUID,                     -- clips1 指向其来源 clips0
  start_ms BIGINT NOT NULL, end_ms BIGINT NOT NULL,
  clip_type TEXT,                     -- 金句|冲突|福利|干货|互动|演示...
  scores JSONB,                       -- {hook,flow,value,trend,reasons{...}}
  rank_score REAL,                    -- 批内归一 0-100
  quote TEXT, reason TEXT, title TEXT, caption TEXT,
  hook_plan JSONB,                    -- 钩子决策（§8.3），可空
  adopted BOOLEAN,                    -- 人工采纳标记（clips1）
  rejected_reason TEXT,
  created_by TEXT NOT NULL,           -- ai | user:<id>
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 任务与进度
CREATE TABLE task (
  id UUID PRIMARY KEY,
  project_id UUID REFERENCES project(id),
  kind TEXT NOT NULL,                 -- transcribe|analyze|render|hook|draft|publish_pack
  stage TEXT NOT NULL,                -- 当前阶段
  progress JSONB,                     -- {stage,done,total,percent,degraded[],message}
  status TEXT NOT NULL,               -- pending|running|paused|done|failed|cancelled
  receipt JSONB,                      -- 完成回执（审计）
  error TEXT,
  created_at TIMESTAMPTZ DEFAULT now(), updated_at TIMESTAMPTZ DEFAULT now()
);

-- 成片产物
CREATE TABLE artifact (
  id UUID PRIMARY KEY,
  project_id UUID, candidate_id UUID,
  kind TEXT NOT NULL,                 -- mp4|srt|cover|caption|draft|publish_pack|evidence
  platform TEXT,                      -- douyin|kuaishou|bilibili|xhs|shipinhao|tiktok...
  file_path TEXT NOT NULL, bytes BIGINT,
  meta JSONB,                         -- 切点/取景模式/响度/钩子版本/AIGC标记...
  content_id TEXT,                    -- 稳定内容ID（回流对账键）
  created_at TIMESTAMPTZ DEFAULT now()
);

-- 发布与回流
CREATE TABLE publication (
  id UUID PRIMARY KEY,
  artifact_id UUID REFERENCES artifact(id),
  platform TEXT, account TEXT, published_at TIMESTAMPTZ,
  url TEXT, status TEXT               -- planned|published|removed
);
CREATE TABLE feedback (
  id UUID PRIMARY KEY,
  publication_id UUID,
  metrics JSONB,                      -- views/likes/comments/shares/orders...
  imported_at TIMESTAMPTZ, source_file TEXT
);

-- 提示词资源
CREATE TABLE prompt_template (
  id UUID PRIMARY KEY, name TEXT, live_type TEXT,
  body TEXT NOT NULL, version INT, active BOOLEAN
);
```

规则：
- `clips0` 只由 AI 写入；人工任何修改生成/更新 `clips1`（带 parent_id）；**渲染只读 clips1 且 adopted=true**
- 所有 AI 产物带 `created_by='ai'`，人工操作记 `user`，审计可回放
- transcript 按 cache_key 命中即复用；换引擎/参数自动失效

## 5. 引擎抽象层（studio/engines/base.py 接口契约）

```python
from typing import Protocol, runtime_checkable
from dataclasses import dataclass

@dataclass(frozen=True)
class Word:
    text: str; start_ms: int; end_ms: int; speaker: str | None = None

@dataclass(frozen=True)
class TranscriptResult:
    words: list[Word]
    sentences: list["Sentence"]
    engine: str; model: str; params_hash: str
    degraded_from: str | None = None   # 降级来源，写回执

@runtime_checkable
class ASREngine(Protocol):
    name: str
    requires_gpu: bool
    def available(self, ctx: "EngineContext") -> tuple[bool, str]: ...
    def transcribe(self, audio_path: str, *, hotwords: list[str],
                   language: str, progress: "ProgressFn") -> TranscriptResult: ...

class Diarizer(Protocol):
    def assign_speakers(self, tr: TranscriptResult, audio_path: str,
                        progress: "ProgressFn") -> TranscriptResult: ...

class SignalExtractor(Protocol):
    name: str
    def extract(self, material: "MaterialRef",
                progress: "ProgressFn") -> "SignalTrack": ...
    # SignalTrack: {bucket_ms:5000, series:{danmaku:[...],loudness:[...],...}}

class LLMClient(Protocol):
    def chat_json(self, system: str, user: str, schema: dict,
                  *, max_retries: int = 2) -> dict: ...
    # 输出必须过 JSON Schema 校验，失败重试后仍失败→任务 failed（不静默）

class HookGenerator(Protocol):
    level: int                          # 1文字 2TTS 3B-roll 4生成视频
    def generate(self, clip: "ClipPlan", ctx: "EngineContext",
                 progress: "ProgressFn") -> "HookAsset | None": ...
    # 返回 None = 生成失败/写不出 → 上层自动跳过该级钩子（宁缺毋滥）

class Renderer(Protocol):
    def render(self, plan: "RenderPlan", progress: "ProgressFn") -> "ArtifactRef": ...
```

**Registry 规则**：
1. 每阶段在 `profiles/*.yaml` 声明有序引擎链，如 ASR: `[bailian, whisper_cpu_int8]`（A）/ `[whisper_large_v3_gpu, paraformer_gpu, bailian]`（B）
2. 启动与任务开始时逐个 `available()` 探测（CUDA/模型文件/Key/网络），取第一个可用；**降级必须写 task.progress.degraded 与回执**
3. `mock` 引擎永远可用（测试/演示），产出确定性假数据
4. 设置页引擎列表 = registry 探测结果，不可用项不展示

**缓存键**：`sha256(file_fingerprint | engine | model | params_hash)`；转写/信号/渲染基础成片三级缓存，目录可配置（本机不下载 GPU 大模型权重）。

## 6. 管线编排与进度事件

### 6.1 阶段状态机（project.status）

```
ingested → transcribing → signaling → analyzing → candidates_ready
        → reviewing(人工) → hooking → rendering → compliance → packed
        → (publishing → feedback) 任意阶段可 failed/cancelled；paused 支持续跑
```

### 6.2 进度事件（复用上游 WebSocket + SQLite 快照机制，不另起 SSE；事件格式扩展如下，前端数字增长的数据源）

> 05 号笔记实测：上游服务器模式 Redis PubSub→WS 网关（progress_event_service.py），桌面/CLI 为 SQLite 快照+监听器/轮询（simple_progress.py:291-313）。studio 层在其 payload 上扩展 done/total/unit/degraded 字段，保持与上游 ProgressEvent 兼容。

```json
{"task_id":"...","stage":"transcribing","done":37,"total":128,
 "unit":"分钟","percent":28.9,"message":"云端ASR转写中",
 "degraded":[{"from":"whisper_large_v3_gpu","to":"bailian","reason":"no CUDA"}],
 "ts":"2026-11-12T10:00:00Z"}
```

- 每阶段必须上报 done/total（转写按音频分钟、分析按分段数、渲染按条数、钩子按步数）
- 心跳 ≤2s 一次；长阶段（CPU 转写）每完成一个分片即上报
- 任务重启恢复：Celery 任务幂等（按 task_id 查已完成分片跳过）；运行中任务被杀→标记 interrupted，不偷偷续跑

### 6.3 取消/失败语义

- 取消：当前 ffmpeg 子进程 terminate，已完成产物保留，临时文件清理
- 失败：保留已完成阶段缓存，重试从失败阶段续跑；错误信息含阶段+引擎+原始报错（脱敏 Key）

## 7. LLM 契约（studio/contracts/，全部 JSON Schema 强校验）

### 7.1 选段输出（analyze 阶段）

```json
{"candidates":[{
  "start_ms": 183400, "end_ms": 241200,
  "clip_type": "福利",
  "quote": "直接给你干到39块9，拍一送三",
  "reason": "价格反差+赠品，福利感强",
  "scores": {"hook":9,"flow":8,"value":9,"trend":7,
             "reasons":{"hook":"开口即价格爆点","flow":"有报价有收尾","value":"省钱利益明确","trend":"低价福利常青"}},
  "title": "299耳机今天39.9还拍一送三",
  "caption": "…含3-6个话题标签"
}]}
```

**铁律（代码强制，不靠 prompt 自觉）**：
- 时间戳必须能反查到 transcript 句子/词边界：后端做吸附（句→词→镜头三级），吸附偏移 >2s 的候选丢弃并记回执
- quote 必须是转写原文子串（模糊匹配容错错字≤2），防 LLM 编造
- 时长硬约束（live_type 预设：带货 15-60s/知识 30-90s/故事 60-180s，可项目级覆盖）
- 重叠候选 NMS 去重（IoU>0.5 保留高分）
- 批内 rank_score 归一（四维加权→排名→映射 40-99），弱片（<60）标 `not_recommended`

### 7.2 复审环（deep-optimize，移植 openclip 思路）

`judge`（独立成段？0-1+理由）→ 不合格 `repair`（仅允许扩/缩边界到邻近句界）→ `rejudge` → 仍不合格丢弃。每轮输入输出全落回执。开关默认开，成本敏感可关。

### 7.3 钩子决策（hooking 阶段）

```json
{"hook_plan":{
  "native": {"type":"cold_open|flash_forward|none","source_ms":[..,..],"confidence":0.0},
  "l1_text": {"text":"悬念句≤20字","style":"big_word"},
  "l2_tts": {"text":"…","voice":"edge:zh-CN-XiaoxiaoNeural"},
  "l3_broll": {"prompt":"…","duration_s":2},
  "l4_gen": {"prompt":"…","first_frame_prompt":"…","duration_s":3}
}}
```

决策树（代码实现，LLM 只填内容不做决策）：native.confidence≥0.8 → 用原生；否则 L1 必做（写不出则跳过）；L2/L3/L4 按项目开关+候选 rank 门槛（L4 仅 top3 且人工确认后才生成）。**L4 生成前弹人工确认（含预估费用），绝不静默计费**。

## 10. 关键算法与 ffmpeg 规范（render_ffmpeg.py 实现依据）

1. **切割**：切点吸附词边界；`-ss/-to` 精确切割重编码；每切点 `afade=t=in:st=0:d=0.03,afade=t=out` 防爆音；关键帧对齐且无画面滤镜时 stream copy 直拷
2. **竖屏重构**：沿上游人物取景；策略改「舒适优先」——单人能装进 9:16 就锁机位到下一镜头，超画幅才平滑跟随，持续漏检回正居中；回执记录每镜头模式
3. **字幕**：词级时间戳逐词点亮（ASS  karaoke 或 drawtext 分段）；语义断行（标点/结构助词，不拦腰）；**最后烧字幕**（先叠贴片/动效）；字体/字号/安全区按平台预设
4. **响度**：`loudnorm=I=-14:TP=-1.5:LRA=11` 两遍法；BGM 人声闪避（sidechaincompress）且 BGM ≤-22 LUFS
5. **去气口**：词间隙 >0.6s 且 silencedetect 确认且 VAD 无人声，三条件齐才剪；保留 0.25s 呼吸口可选；剪除映射表写回执，字幕时间轴同步重映射
6. **cold-open**：钩子句区间复制到片头（词边界），原位置保留或跳剪（项目开关）；flash-forward：0.3-1s 高能画面闪现+whoosh 音效；定位失败自动跳过
7. **L1 贴片**：开头 2s、上 1/3、大字描边、淡入淡出避开人脸区（人脸检测框避让，无检测则固定安全区）
8. **封面**：响度峰提名→成片内比清晰度/曝光/信息量→淘汰黑白场/模糊帧→取优
9. **AIGC 标识**：L3/L4 产物烧显式角标 + 写元数据（ffmpeg `-metadata comment=`）；合规报告记录
10. **自检**：渲染后扫黑屏/长静音/冻结帧/主体出框/半词切点，问题写回执；可安全自愈项修复后重检
