## 2. ASR（对我们方案影响最大的一节）

- 引擎（utils/speech_recognizer.py:25-27,585-598）：whisper_local（**faster-whisper 1.2.1**，CTranslate2 无 PyTorch，whisper_runtime.py:5-6,40-47）/ sensevoice_local（FunASR 1.3.14 + torch CPU 隔离子进程，sensevoice_runtime.py:18,31-33）/ cloud
- **词级时间戳：本地有（word_timestamps=True，speech_recognizer.py:742,770；sidecar .words.json，word_timing.py:14-15），云端没有**（cloud_transcription.py:295-296 转写完成后删除 words sidecar）
- 云端：百炼 DashScope 为主（qwen-audio-3.1-asr-flash / qwen3-asr-flash / fun-asr / paraformer-v2，asr_model_catalog.py:10-12），兼容 OpenAI /audio/transcriptions
- 说话人分离：云端 qwen-audio-3.1-asr-flash 支持（cloud_transcription.py:160-161）；本地有配置项 enable_speaker_diarization（speech_recognizer.py:77）
- **热词：全仓无实现**（grep hotword/热词 零命中）→ 我们集成 FunClip SeACo-Paraformer 补上，属净新增

**方案修正**：词边界切割依赖词级时间戳 → cpu-cloud 档案若走云 ASR（句级），切割只能句边界吸附；要词级必须本地引擎（whisper int8 CPU / Paraformer）。04 号 §7.1 三级吸附（句→词→镜头）中「词」级在云 ASR 时自动降为句级，回执标注。

## 3. LLM 选段

- 快路径 clip_finder.py：整段字幕按「行号|时间|文本」喂模型（:9,207），**模型输出起止行号**+title/reason/score(0-1)（:93-95），落地转 SRT 时间格式（:223-226）——行号反查天然防时间戳幻觉，比我们 04 号契约的「ms+quote 校验」更巧，**吸收此设计**
- 窗口：云端 60min/70K 字符，本地 20min/12K（:31-67）；重叠去重阈值 0.5（:34,152-165）
- 评分：单一 final_score(0-1)+recommend_reason，**非四维分项** → 我们的四维评分（hook/flow/value/trend）是净新增
- 边界对齐：quality.py refine_timeline（snap_window_sec=3.0 吸附 cue 边界，:64,212,320-321；重叠合并:336-357；时长伸缩:359-384；select_clips 阈值+fallback 补齐:553-587）

## 5. 竖屏取景

- services/studio/framing.py（1549 行）：**OpenCV YuNet ONNX 人脸检测**（:45-46，模型在 backend/assets/models/），不是 MediaPipe/YOLO
- shot-aware：ffmpeg scene-change 分镜（:3-4,48）；嘴部运动判说话人（:55）；单人脸 crop 居中、多人/无脸 fit 模糊背景（:13-17）

## 8. 进度协议（修正 04 号的 SSE 假设）

- 服务器：Redis PubSub→WebSocket 网关（progress_event_service.py:3,13,91-154；websocket_gateway_service.py:12-18），事件 ProgressEvent={task_id,progress,step,total,phase,message,status,seq,ts,meta}（:19-31），200ms 节流
- 桌面/CLI：SQLite 快照+监听器/轮询（simple_progress.py:166-196,291-313），payload={project_id,stage,percent,message,ts}
- **不是 SSE** → 方案修正：复用上游 WS+SQLite 快照机制，studio 层扩展事件字段（done/total/unit/degraded），不另起 SSE 平行体系

- **cp313 原生包必须钉 wheel**（av 18.1.0 / ctranslate2 4.8.2 / onnxruntime 1.31.0 / tokenizers 0.23.3，--only-binary，whisper_runtime.py:33-47），否则 pip 回溯源码编译空转一小时

## 10. 对 04 号方案的修正汇总（已回写）

1. DB：P0 用 SQLite（上游桌面/CLI 强制），Postgres 延后到 B 端多用户

5. 取景：上游是 YuNet，我们的「锁定优先」策略在其 framing.py 上改参数/策略，不换技术栈
6. 热词/四维评分/clips0-clips1/信号层/钩子/合规：确认为净新增，上游无等价物
