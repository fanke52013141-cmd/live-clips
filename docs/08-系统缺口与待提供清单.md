## 建议推进顺序

**第一步（解锁真实验收，最高杠杆）**：A1 真实直播样本 → 一次性补验 ASR/选段/渲染/UI（B 表大半）。
没有真实样本，所有「效果」结论都只是装配正确，无法判断产品好不好用。

**第二步（按你的商业路径二选一）**：
- 走「人工精修+剪映」路线：A5 capcut-mate 部署 + A8 剪映真机 → 草稿端到端
- 走「自动发布」路线：A6 许可证+授权 → 真实发布泵 + 回流飞轮

**第三步（质量与生产化）**：F 黄金集基线（持续迭代护栏）→ C 竖屏人物取景（观感）→ D 队列/鉴权/部署（团队/公网）。

**第四步（增强）**：A3 生成钩子 / A7 本地 Wan（5080）/ A4 说话人分离。
