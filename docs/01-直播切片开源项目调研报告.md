# 直播切片开源项目调研报告

- 日期：2026-11-12
- 调研方式：全网检索（GitHub 仓库 README、官方帮助文档、技术社区评测）+ GitHub API 星数实测
- 星数说明：标注「实测」的为当日通过 GitHub API 直接读取；标注「未核实」的因 API 限流未取到，仅供参考
- 配套阅读：本报告第 8 节给出针对「自研直播切片软件」的落地方案建议

---

## 1. 摘要（TL;DR）

1. **开源界已经把「直播切片」跑通了四条成熟路线**：弹幕/信号驱动、ASR+LLM 语义驱动、多信号融合驱动、以及「录制→切片→包装→发布」全链路无人值守。高星代表：AutoClip（10.3k★）、FunClip（6.5k★）、ChopperBot（2.9k★），周边生态 MoneyPrinterTurbo（142k★）、VideoLingo（19.2k★）。
2. **技术管线高度收敛**：几乎所有项目都是同一条流水线的变体——`获取素材 → 音频提取 → ASR 词级转写 → (弹幕/音频/视觉信号) → LLM 选段打分 → 语义边界对齐切割 → 竖屏重构+字幕+标题封面 → (人工审核) → 发布`。差异只在「用什么证据找爆点」和「自动化到什么程度」。
3. **商业标杆 OpusClip 的核心壁垒是多模态**（ClipAnything：视觉+音频+情绪三通道，不只靠字幕）和 **Virality Score 四维评分（Hook/Flow/Value/Trend）**。它已内置「AI 生成钩子」：自动文字钩子贴片 + TTS 配音钩子 + AI B-roll——**你想做的「自制钩子」方向，商业上已被验证，但主流做法是文字/配音钩子，纯文生视频钩子是更激进的差异化**。
4. **好切片的第一要素是前 3 秒钩子**，行业数据：约 72% 用户在 3 秒内决定去留；3 秒留存每 +10%，完播率约 +15~20%。钩子分「原生钩子」（直播里本来就炸的瞬间，靠高潮前置 cold-open / 爆点闪现 flash-forward 挖出来）和「自制钩子」（文字贴片、TTS 悬念句、AI 生成画面）。**开源项目里 hotclip 已把两种原生钩子手法产品化，且给出关键数据：仅 0.04% 的切片有视觉钩子——这是空白点**。
5. **你的想法（文生图/图生视频做钩子 + 切片正文）可行且有差异化空间**，但要注意：钩子必须与正文兑现一致（货不对板反而拉低完播）、平台对 AIGC 有强制标识要求、精美片头反而可能降低互动（数据：粗糙直入互动率 +12.7%）。建议钩子走「信息型」而非「炫技型」。
6. **落地建议**：不要从零造轮子。MVP 用「ASR + LLM 选段 + 人工审核 + ffmpeg 切割」起步（参考 AutoClip/FunClip/hotclip 的管线），第二阶段加弹幕/音频多信号与钩子工坊（文字钩子→TTS 钩子→生成式视觉钩子逐级上），第三阶段才做录制与自动发布矩阵。版权授权与平台判搬运是业务生死线，产品要内置「授权台账 + 二创增量 + AIGC 标识」。

## 2. 开源项目全景：四条技术路线

### 路线 A：信号驱动（弹幕/音频/画面，弱 LLM 或无 LLM）

**核心思想**：观众的实时反应（弹幕密度、礼物、点赞）和音画能量（音量突变、笑声掌声、镜头切换、运动强度）就是「哪里精彩」的天然标注。不依赖语义理解，成本低、可实时。

| 项目 | 星数 | 语言 | 信号 | 特点 |
|---|---|---|---|---|
| ChopperBot (Geniusay) | 2,858 实测 | Java | 弹幕评分 | 老牌全链路：热门监控→录制→弹幕切片→AI 标题封面→多账号发布，插件化 |
| douyin-slicer (lynytt) | 未核实 | Python | 音量+兴奋度+画面运动+弹幕密度 | 轻量，四维加权（有弹幕 35/25/15/25，无弹幕自动切三维），15-60s 输出 |
| douyin-living (Yht20927) | 未核实 | Python | 弹幕+音频+视觉+ASR 四路 | 「3 层 AI + 7 项数学方法」融合打分，Z-Score 标准化→加权→自适应阈值→NMS 去重→语义边界对齐 |
| auto-editor (WyattBlue) | 5,852 实测 | Nim | 音频/运动 | 不是找高光，而是自动剪掉静音/无效片段（去气口），常作预处理 |
| autocut (mli) | 7,846 实测 | Python | ASR 文本 | 李沐出品，「用文本剪视频」：删字幕句即删视频段，口播粗剪神器 |

**优点**：快、便宜、可直播中实时打标；游戏/才艺/娱乐直播（语义少、能量多）效果好。
**缺点**：弹幕少或水军刷屏时失效；音量高≠内容好（可能是 BGM）；切出来「热闹但没信息」，带货/知识类直播不适用。

### 路线 B：ASR + LLM 语义驱动（当前主流）

**核心思想**：先把整场直播转成带词级时间戳的文字稿，让 LLM 像剪辑师一样「通读全文」，挑出金句/冲突/干货/福利片段，输出时间区间，再反查时间戳切割。**LLM 只负责「挑哪段」，时间戳由 ASR 反向对齐，不让 AI 猜时间**——这是所有成熟项目的共同铁律。

| 项目 | 星数 | 技术栈 | 亮点 |
|---|---|---|---|
| AutoClip (zhouxiaoka) | 10,322 实测 | FastAPI+Celery+React，Qwen LLM | 当前最火的桌面级成品：贴链接→下载→转写→LLM 打分→句边界切割→自动取景竖屏→字幕封面标题→ZIP 发布包。实测 1h43m 视频 7.5 分钟出 10 条，模型成本约 9 分钱 |
| FunClip (modelscope) | 6,542 实测 | FunASR Paraformer + CAM++ 说话人分离 + LLM | 阿里通义官方。中文 ASR 最强开源方案之一，热词定制（人名/术语）、按说话人剪辑、Gradio 零代码界面 |
| hotclip (xixihhhh) | 未核实 | Electron 桌面，本地 SenseVoice/Paraformer/FireRedASR2 + Ollama | **功能最完整的开源直播切片工具**：九路证据链（文本/响度/镜头/运动/表情/视觉/弹幕/语气/笑声掌声）、爆款分四维评审、cold-open 高潮前置、flash-forward 爆点闪现、去气口、剪映草稿导出、发布数据回流 A/B、全程本地不上传。AGPL-3.0 |
| openclip (linzzzzzz) | 未核实 | Python+Streamlit，Whisper/Paraformer 按语言路由 | 轻量流水线，--user-intent 自然语言定向选段、deep-optimize 边界复审、说话人参考音频映射姓名 |
| AI_Slice (VicPlaine) | 未核实 | React+FastAPI+PostgreSQL，千问 ASR/LLM | 三模式（直播回放/播客/课程），浏览器 FFmpeg.wasm 抽音频只传音频不传视频，人工审核标题文案后导出 |
| video-clipper (zzzzzjh1101) | 未核实 | 纯 Python CLI + Markdown 流程 | Agent Skill 形态（Claude Code/Codex 可驱动），13 种切片类型独立策略，词边界切割+30ms 淡入淡出防爆音 |
| ai-highlight-clip (zzqn2026) | 未核实 | PyQt5 桌面，Whisper+千问 | 滑动窗口扫描+高光指数打分+爆款标题，批量目录处理 |
| live-mixer (Chyona) | 未核实 | Go+Gin+PostgreSQL+capcut-mate | **B 端工作台思路**：素材入库→ASR→AI 粗选 clips0→人工精修 clips1→生成剪映草稿→一键成片，「AI 粗选+人工精修」双路径 |

**优点**：语义完整、切口自然、能出标题/文案/评分，知识/带货/口播类效果最好；成本极低（一场直播几分钱到几毛钱 LLM 费用）。
**缺点**：纯文本盲选——画面梗（表情、操作、产品展示）看不见；ASR 错字会传导；长直播需要分段+去重策略。

### 路线 C：多信号融合（A+B 合体，商业产品的方向）

**核心思想**：单路信号都会骗人，**多路信号同秒共振才可信**——音量高可能是 BGM，弹幕高可能是刷屏，「音量+弹幕+笑声+文本金句」一起亮才是真爆点。

- **hotclip**：九路证据链 + 信号共振 + 算力聚焦（信号峰引导抽帧，避免前半段热闹挤掉后半段安静但重要的场景）+ 本地多模态视觉模型（Ollama qwen-vl 看九宫格接触表）复核画面。
- **douyin-living**：弹幕（密度/加速度/熵值/情感/反刷屏）+ 音频（RMS/频谱质心/MFCC/笑声掌声）+ 视觉（场景切换/光流/人脸数）+ ASR（关键词/说话人交替/话题切换），按直播类型（游戏/带货/才艺）配权重预设。
- **OpusClip ClipAnything**（商业闭源）：视觉（物体/动作/屏显文字）+ 音频（非语音情绪声）+ 情感（情绪与人际张力）三通道多模态理解，支持自然语言 prompt（"找出所有进球"），能剪无对白的游戏/体育/vlog。

### 路线 D：全链路无人值守（切片工厂）

**核心思想**：切片只是中间一环，商业闭环是「开播自动录 → 下播自动切 → 审核闸门 → 内容池 → 多账号匀速发布 → 数据战报」。

- **ClipStream (mumuopen)**：纯 Go 单二进制，B站/虎牙开播检测、断流续接、whisper×弹幕双信号、LLM 精选 20-60s、翻译+edge-tts 配音、**三档审核闸门（硬拒/留人工/自动过）**、发布泵（间隔/每日/在途三闸+抖动防风控）、扫码登录、断电任务恢复。Windows 服务器挂机生产验证。
- **ChopperBot**：热门监控（谁火盯谁）+ 账号标签路由（LOL 搞笑号/Apex 操作号各取所需）+ 插件热插拔。
- **lxgic-clipper**（海外）：Twitch/Kick/YouTube 录制，音频尖峰+聊天速度+游戏状态+视觉运动检测，Postiz API 分发 32 平台，检测→上传约 3 分钟。
- **周边生态**：biliup/录播姬（录制）、social-auto-upload（多平台发布）、Postiz（海外社媒管理）。

### 相关但不同赛道：短视频「生成」而非「切片」

这些项目不做直播切片，但你的「自制钩子」会用到它们的技术栈：

| 项目 | 星数 | 说明 |
|---|---|---|
| MoneyPrinterTurbo | 142,650 实测 | LLM 脚本→TTS→字幕→素材匹配→合成，一键短视频 |
| VideoLingo | 19,200 实测 | Netflix 级字幕切分+翻译+配音对齐（出海切片刚需） |
| ShortGPT | 8,157 实测 | 短视频全流程自动化框架（字幕/配音/素材引擎化） |
| NarratoAI | 未核实 | 影视解说：LLM 写解说词→按解说词反选画面→配音成片 |
| MoneyPrinterPlus | 未核实 | 批量短视频+多平台发布 |

**NarratoAI 的思路对你特别有参考价值**：它是「先有文案（钩子/解说），再让文案驱动画面选择」——正好是你设想的「自制钩子→切片内容」的镜像实现。

## 3. 高星项目深度拆解

### 3.1 AutoClip（10,322★，实测）——当前开源切片的「产品化天花板」

**管线六步**：
1. 听完全片：ASR 转写（可用平台现成字幕，也可本地识别）
2. LLM 通读全文：判断哪句最炸、哪个观点有料
3. 候选打分：精彩度评分（0-100）排序
4. 精确切割：切点吸附句子起落，不拦腰截断
5. 自动字幕+自动取景：镜头跟随说话人，竖屏人物不跑位
6. 自动包装：标题、封面、简介、话题标签，ZIP 发布包

**关键设计**：
- **平台方言**：抖音/小红书默认竖版访谈式（上下留白放大标题），TikTok/Reels/Shorts 满屏播客式，B站/YouTube 保留横版。每平台最多 10 条合格片段，其余进备选。
- **AI 出初稿、人做终审**：候选列表逐条预览/下载，不满意打开编辑器手改。
- **成本工程**：实测 2h45m 中文播客 8.7 分钟出片、LLM 费用 1 毛 3；旧版要 65 分钟——说明「分段并发+缓存」优化空间巨大。
- 本地渲染，视频不上传云端（只传文本给 LLM）。

**局限**：游戏/纯音乐等无说话内容素材效果差（文本驱动的通病）；无弹幕信号接入。

### 3.2 FunClip（6,542★，实测）——中文 ASR 基建首选

- Paraformer-Large：中文识别+一体化词级时间戳，ModelScope 下载 1300 万+。
- SeACo-Paraformer 热词：人名/品牌/术语一次配置全场纠错（直播切片刚需——主播名、商品名、黑话）。
- CAM++ 说话人分离：连麦/PK/多人访谈按人剪辑、字幕按人上色。
- LLM 剪辑：SRT 喂给 Qwen/GPT，prompt 定义选段标准，输出「[开始-结束] 文本」再反查切割。
- SenseVoice 可选：附带情绪识别+音频事件检测（笑声/掌声）——等于自带一路音频信号。

**定位**：它不是完整切片产品，而是**最适合被你集成的 ASR+说话人+LLM 剪辑引擎**（MIT 协议，CLI 两阶段可脚本化）。

### 3.3 hotclip（星数未核实，2026 年活跃更新）——开源里最接近你设想的产品

值得逐条研究的差异化功能（全部来自其 README，建议 clone 实测验证）：

**找爆点**：
- 九路证据链，多路同秒共振才可信；弹幕文件自动发现（B站录播姬 .xml / 抖音 .jsonl），礼物/SC/点赞按互动计权（花钱的票比弹幕硬），单人刷屏贡献封顶。
- 爆款分=四维（钩子/结构/价值/热点）加权后**同批次相对排名归一**，明确「是排序不是预测」；弱片自动标「不建议发布」。
- LLM 只挑段并引用原文，时间戳由逐字转写反向对齐；导出前 Paraformer 二遍对齐修正切点。
- 参考视频驱动：丢一条对标爆款，本地实测节奏生成风格画像，选段向对标靠拢。
- **发布数据回流**：导入平台播放/互动 CSV，归纳高低表现内容的题材/钩子/时长共性，反哺下一轮选段；一片多版本地 A/B（同平台、72h 窗口、每版≥500 播放才比较）。

**钩子（与你的想法直接相关）**：
- **开场钩子贴片**：AI 写悬念句，大字烧在开头 2 秒上三分之一，淡入淡出避开主体；写不出就不加。
- **高潮前置 cold-open**：把全片最炸的钩子句剪到开头再接正片（商业工具锁付费档的功能）。
- **爆点闪现 flash-forward**：正片前先闪 0.3-1 秒全片最炸瞬间再切回。README 称「全网仅 0.04% 切片有 visual hook」——**视觉钩子是公认空白**。
- 8 种钩子角度 × 5 类 CTA 生成发布文案。

**成片质量**：舒适优先竖屏取景（能锁机位就锁，不追脸晃）、语音感知去气口（三重判定防吞人声）、剪口头禅、-14 LUFS 响度归一、TransNetV2 镜头边界吸附、出片自检（黑屏/静音/冻结/主体出框）、智能封面。

**合规与分发**：变形度评分（二创增量低于 40 黄牌警告，防判搬运）、120+ 违禁词 lint、AIGC 显式+隐式标识、分发留证包（源片区间台账+前后 3 分钟源片切段，被质疑搬运时拿得出证据）、一片多版反指纹（真差异而非镜像抽帧伪原创）、剪映草稿导出（AI 粗剪→剪映精修接力）。

**工程形态**：Electron 桌面双击即用 + Headless CLI + 本地 MCP Server + Agent Skill；全程本地可 100% 离线（Ollama）；AGPL-3.0（**注意：商用集成需评估传染性，独立使用/参考思路无碍**）。

### 3.4 ChopperBot（2,858★，实测）——弹幕驱动+矩阵分发的老前辈

- 模块：热门监控（自动发现全网爆款直播）→ 爬虫录制 → 弹幕评分切片 → AI 标题/封面/简介 → 账号标签路由发布。
- 弹幕打分选高分区间，并分类（游戏/搞笑/争论）打标签；账号设人设标签（"LOL搞笑""Apex操作"），切片自动流向匹配账号。
- Java 插件化架构、本地 JSON 存储零数据库依赖、可视化控制台。
- 2025-08 后停更（实测 pushed_at），思路仍值得学，代码不建议直接基座。
- ClipStream 是其模块思想的 Go 重写，工程健壮性更好（进程隔离、断电恢复、磁盘治理、背压洪闸）。

### 3.5 OpusClip（商业闭源，10M+ 用户）——必须对标的行业标杆

- **ClipAnything 多模态引擎**：视觉+音频+情感三通道，脱离对白也能剪（游戏/体育/vlog）；自然语言 prompt 定向找片段；内置「叙事模板库」（与获奖制作人合作建的 hook→build→payoff 结构库）。
- **Virality Score 0-99**：Hook（开头抓人且扣题）/ Flow（叙事完整有收尾）/ Value（情绪共鸣与有用）/ Trend（贴合热点）四维。社区逆向分析约 18 个参数：前 3 秒钩子强度（权重约 20%）、叙事闭合（约 15%）、信息密度（约 10%）、面部手势、语调变化、具体数字、时长适配等。**本质是同批排序器，不是爆款预言机**。
- **AI 钩子已产品化**：Auto Text-Overlay Hook 默认开启（给 top 10 切片自动生成一行文字钩子）；AI Voiceover（TTS 钩子/评论音轨）；AI B-roll（按语义自动插素材画面/图表）。
- ReframeAnything：7 种自动版式（Fill/Fit/Split 双人上下/三人/四人/屏幕分享/游戏 30% 主播+70% 画面），说话人切换自动摇镜。
- Agent Opus（2025-08）：从想法/文章/音频**从零生成**短视频——「切片」与「生成」两条产品线合流的信号。
- 定价：按源视频分钟扣积分（1 credit≈1 分钟），$15-29/月档。开源社区对其最大抱怨：贵、必须上传云端、黑盒断章取义。

│ 原生: cold-open 高潮前置 / flash-forward 爆点闪现        │

**工程共识（所有成熟项目都遵守）**：
- 切点必须落在词/句边界，绝不切断音节；切点加 30ms 音频淡入淡出防爆音。
- 转写结果缓存（源文件不变永不重转写）；一切产物进工作目录，源文件永不修改。
- 字幕最后烧（先叠动效转场再烧字幕）；字幕用转写原文不「美化改写」。
- AI 只出候选，人终审；每一刀可审计（clips.json 回执记录切点理由/剪了什么）。
- 宁短勿长，前 3 秒必须有钩子。

## 5. 一个好的直播切片，要素是什么

综合 OpusClip 评分体系、hotclip 四维评审、国内运营方法论，按权重排序：

### 5.1 钩子（前 3 秒）——权重最高
- 行业数据（运营文档口径，非平台官方）：用户决策中位数约 2.8 秒，约 72% 用户 3 秒内决定去留；3 秒留存 >40% 进二级流量池、>60% 三级、>80% 爆款池；3 秒留存每 +10%，完播率约 +15~20%。
- 钩子三载体：**文案钩子**（第一句话/屏幕大字）、**画面钩子**（第一帧给什么）、**声音钩子**（语气/音效/BGM 切入点）。至少占一样，最好两样叠加。
- 六类可套用模板：痛点直击 / 反常识断言 / 悬念留白 / 利益前置 / 身份圈人 / 画面前置（高潮前置）。
- 反直觉结论：**粗糙直入 > 精美片头**（精美开场动画互动率反而低）；片头每多 0.3 秒非必要信息点击率约 -11.7%；「大家好我是XX」= 自杀式开头。

### 5.2 结构完整（Flow）
- 一条切片 = 一个独立闭环：钩子 → 展开 → 收尾（payoff/CTA）。没头没尾的「半截话」是最常见废品。
- 独立可理解：没看过直播的人也能看懂。带货切片要保留「仅适用于/不包含」等改变结论的限定词，删掉已失效的「现在进直播间/今晚最低价」口播。
- 信息密度：删语气词、重复话术、无信息增量过渡句；宁短勿长（带货 15-60s，知识/观点 30-90s，故事/访谈可到 1-3min）。

### 5.3 价值与情绪（Value）
- 四维价值：信息（干货/认知差）、情感（共鸣/争议）、娱乐（笑点/冲突/节目效果）、利欲（福利/价格反差）。
- 带货特化：按「购买问题」选段（怎么安装/尺寸对比/哪些人不适合），保留完整演示证据，比催单口播更有长尾转化。
- 情绪峰值：笑声、掌声、惊讶表情、音调突变、弹幕爆发——多信号共振处。

### 5.4 制作质量（表观门槛）
- 竖屏 9:16 重构：主体（说话人/商品/手部操作）始终在画面内；能锁机位就锁，别追脸晃。
- 动态字幕：词级时间戳逐词点亮、语义断行不拦腰截断、关键词高亮；字幕是完播率刚需（大量用户静音刷）。
- 响度归一 -14 LUFS；人声清晰（降噪）；BGM 压在人声之下（约 -22 LUFS 以下）并自动闪避。
- 封面：从成片里优选清晰/有信息量的帧 + 大字标题；标题用观众会搜的问题句。
- 平台安全区：字幕避开各平台 UI 遮挡（点赞栏/文案区）。

### 5.5 合规与差异化（活下来）
- 授权：切片分销必须拿主播/MCN 书面授权（素材范围/账号/期限/能否投流），无授权=侵权+封号风险。
- 二创增量：平台判搬运看实质创作增量——换音乐/镜像/加速/抽帧不算；重排结构、加解说、加钩子、多版本真差异才算。
- AIGC 标识：按《人工智能生成合成内容标识办法》显式画面标识+隐式元数据标识（用了生成式钩子必须打标）。
- 违禁词：绝对化用语/医疗宣称/虚假限时优惠，发布前 lint。

## 6. 钩子专题：原生钩子 vs 自制钩子（你的核心问题）

### 6.1 原生钩子：直播里本来就有的钩子

你说「这种情况比较难」——**其实开源界已经把它做成了可自动化的手法**，难的不是「有没有」，而是「找得准+放得对」：

| 手法 | 原理 | 已实现项目 |
|---|---|---|
| 高潮前置 cold-open | 把全片最炸的一句/一幕剪到开头 0-3s，再倒回正片 | hotclip（定位失败自动跳过，宁不做不做错）、OpusClip 叙事模板 |
| 爆点闪现 flash-forward | 正片前先闪 0.3-1s 最炸瞬间再切回，制造悬念 | hotclip（与 cold-open 二选一） |
| 金句开头 | LLM 选段时把「片段内最有钩子的句子」吸附为起点，而非机械按时间切 | AutoClip/openclip 的边界优化、video-clipper 硬规则「前3秒必须有钩子」 |
| 弹幕峰值定位 | 观众逐秒投票找出真高能段，作为钩子候选 | ChopperBot/ClipStream/douyin-living/hotclip |

**关键认知**：原生钩子的本质是「重排」而不是「生成」——素材里已经有答案，AI 的工作是找到它并前置。这条路成本低、真实感强、无 AIGC 合规负担，**应该作为默认策略**。

### 6.2 自制钩子：直播里没有，我们造一个

按成本/风险从低到高分四级，**商业产品已验证到第 2-3 级**：

**L1 文字钩子贴片（已验证，默认开启）**
- AI 基于切片内容写一句悬念/痛点/利益大字，烧在开头 2 秒画面上三分之一。
- OpusClip Auto Text-Overlay Hook 默认给 top 10 切片开启；hotclip「写不出悬念句就不加」。
- 成本≈0（一次 LLM 调用），无素材风险，是性价比之王。

**L2 TTS 配音钩子（已验证）**
- AI 写 1-2 句钩子文案 → TTS（可用主播克隆音色）→ 压在开头画面上，原声闪避。
- OpusClip AI Voiceover 明确用途就是 hooks；ClipStream 用 edge-tts 做解说配音。
- 风险：音色不像本人会出戏；克隆音色需授权。

**L3 AI B-roll / 生成式画面插入（商业已验证，开源空白）**
- 按钩子文案生成/检索 1-3 秒画面（产品特写、数据图表、场景示意）垫在开头或正文信息点。
- OpusClip AI B-roll：说到"邮件打开率"自动插图表，说到"东京街头"自动插素材；实测建议 B-roll 占 60-70% 时长，钩子和结尾用真实素材。
- 开源侧几乎没有等价实现——**差异化机会**。

**L4 纯文生图/图生视频钩子（你的设想，最激进）**
- 用即梦/可灵/Seedance/Wan 等生成 3-5 秒「视觉奇观/情景再现/悬念画面」作冷开场，再接切片正文。
- 可行性：技术成熟（图生视频 5-10s 已是标配），NarratoAI/MoneyPrinter 系已验证「文案驱动生成画面」管线。
- **三个必须正视的风险**：
  1. **货不对板**：钩子承诺的正文必须兑现。生成画面与直播内容脱节 → 骗停留 → 完播更差 → 算法降权。运营数据明确「精美片头反而降低互动」，所以生成钩子要走**信息型**（再现争议场景/可视化数据/悬念提问画面），不是炫技型。
  2. **AIGC 合规**：生成画面必须显式+隐式标识；部分平台对 AI 内容流量政策收紧，单场超量发布会被限产。
  3. **成本与抽卡**：生成视频按秒计费且需多次抽卡，批量切片场景成本远高于 L1/L2。建议只对「爆款分 top 候选」启用 L4，且人工审核后才合成。

### 6.3 建议的钩子决策树（产品逻辑）

```
候选切片
 ├─ 片段内自带强钩子(金句/冲突/福利/画面爆点)?
 │    ├─ 有 → cold-open/flash-forward 原生前置 (默认, 零成本)
 │    └─ 无 ↓
 ├─ L1 文字悬念句贴片 (默认, LLM 写不出就不加)
 ├─ L2 TTS 钩子 (可选, 有授权音色时)
 ├─ L3 生成式 B-roll (高分候选, 信息型画面)
 └─ L4 文生视频冷开场 (仅 top 候选 + 人工确认 + AIGC 标识)
每级产物都是「候选」，人勾选后才进成片 —— 绝不静默采用
```

## 7. 与短视频生产方法论的关系

你的判断正确：**直播切片本质是短视频生产的一个子集**，共享同一套「注意力经济学」：

- 平台赛马机制：小流量池测 3s/5s/10s 留存 → 达标进更大池。切片和原创短视频被同一把尺子量。
- 因此切片不能「忠实记录」，必须「重新叙事」：原直播是线性时间流，切片是「钩子→展开→收尾」的闭环重构。这正是 LLM 选段+重排的价值。
- 差异点：切片有**真实感与信任背书**（主播 IP 自带流量，带货转化靠信任），这是纯生成短视频比不了的；所以钩子再花哨也不能破坏「这是真实直播发生的事」的信任感——**生成式钩子只能做「引子/示意」，正文必须是真实素材**。
- 切片带货的商业闭环（授权分销）：MCN 授权 → 矩阵账号二创挂车 → 佣金分成（常见五五/三七，先扣税费与平台手续费）。小杨哥案例：授权账号 1 万+、切片贡献 GMV 约 30%。这说明**切片软件的客户不只是主播本人，更是切片分销团队/MCN**——他们要的是批量、差异化（防同质化判搬运）、合规台账、数据回流。

## 8. 给你的落地方案建议

### 8.1 定位选择（先想清楚卖给谁）

| 定位 | 客户 | 核心能力 | 竞品烈度 |
|---|---|---|---|
| A. 主播自切工具 | 主播/UP主本人 | 本地隐私、一键出片、剪映接力 | 高（hotclip/AutoClip/剪映） |
| B. 切片分销工作台 | MCN/切片团队 | 批量、授权台账、多账号差异化、数据回流 | 中（live-mixer 思路，B端工程化少） |
| C. 钩子工坊（差异化单品） | 所有切片生产者 | 原生钩子挖掘+四级自制钩子+A/B | **低，空白点** |

建议：**以 B 的架构做底座，把 C 做成核心卖点**。A 赛道已有免费开源强者，正面打性价比不明智。

### 8.2 分批实施路线（依赖顺序）

**P0 MVP（验证选段质量）**
- 输入本地直播回放文件（先不做录制）
- ffmpeg 抽音频 → FunClip/FunASR（Paraformer+热词+说话人）或 faster-whisper
- LLM 选段：时间轴文本+prompt（按直播类型：带货/娱乐/知识）→ 候选区间+四维评分+理由+标题
- 人工审核界面：候选列表预览、勾选、微调切点（词边界吸附）
- ffmpeg 切割+字幕烧录+竖屏裁剪（先居中裁剪，不做人脸跟踪）
- 产出：MP4+SRT+标题文案
- 验收：一场 2h 直播出 10 条候选，人工采纳率 ≥50%

**P1 成片质量+原生钩子**
- 弹幕文件接入（录播姬 xml/抖音 jsonl），密度+礼物计权+反刷屏，信号注入 LLM 上下文
- 音频信号（响度峰/笑声掌声，SenseVoice 自带）
- cold-open/flash-forward 原生钩子（定位失败自动跳过）
- L1 文字钩子贴片 + 动态逐词字幕 + 去气口 + 响度归一
- 人脸跟踪竖屏重构（可参考 AutoClip/openclip 实现）
- 剪映草稿导出（capcut-mate）——精修接力，不从零做编辑器

**P2 自制钩子工坊（你的差异化）**
- L2 TTS 钩子（edge-tts 起步，克隆音色需授权流程）
- L3/L4 生成式钩子：钩子文案→文生图→图生视频（接即梦/可灵/Seedance API 或本地 Wan），仅 top 候选启用，人工确认后合成，自动 AIGC 标识
- 钩子 A/B：一片多版（不同钩子角度），发布数据回流对比

**P3 工厂化（按需）**
- 开播检测+自动录制（biliup/yt-dlp）、录播目录监听
- 审核闸门三档（硬拒/留人工/自动过）+ 授权台账 + 违禁词 lint + 分发留证包
- 多平台发布（social-auto-upload）匀速防风控 + 数据战报

### 8.3 技术选型建议

- **基座参考**：hotclip（功能最全，AGPL 注意商用边界，建议参考思路+自研核心）、AutoClip（MIT，管线清晰）、FunClip（MIT，ASR 引擎直接集成）。
- **后端**：Python FastAPI + 任务队列（你熟悉的技术栈，与 duo-podcast 经验复用：frozen Settings、ffmpeg lavfi 测试夹具、mock 模式全链路验证、GPU 实测分离）。
- **ASR**：中文 Paraformer/FireRedASR 本地；说话人 CAM++；热词表必备。
- **LLM**：OpenAI 兼容接口可换（DeepSeek/Qwen/豆包），端侧小模型初筛+云端精读的两级漏斗省钱。
- **切割**：ffmpeg 词边界+30ms 淡化；镜头边界 TransNetV2；竖屏重构 MediaPipe/YOLO 人脸。
- **生成钩子**：先接 API（即梦/可灵/Seedance），本地 Wan2.1 图生视频留作私有化选项（你有 5080 验收经验）。
- **前端**：候选审核台是产品重心（时间轴+波形+弹幕曲线+逐词切点拖拽），可 Electron 或 Web。

### 8.4 必须内置的合规设计

- 授权台账：素材来源/授权范围/账号/期限，发布前核对。
- 二创增量自评（参考 hotclip 变形度评分）：低于阈值黄牌。
- AIGC 标识：生成钩子显式画面标识+隐式元数据。
- 违禁词 lint + 敏感词静音（保留原文可审）。
- 每一刀可审计（clips.json 回执）+ 分发留证包。

## 9. 风险清单

1. **版权**：无授权切片=侵权，头部 IP 投诉率极高。产品必须把授权流程做进工作流，而不是免责声明。
2. **平台判搬运**：像素级去重（镜像/抽帧/加速）已被识别，必须真差异（重排/解说/钩子/多版）。
3. **AIGC 政策**：生成内容强制标识，部分平台限产限量；纯 AI 钩子可能触发审核。
4. **ASR 误差传导**：错字→LLM 误判→切错；热词+二遍对齐+人工复核兜底。
5. **评分迷信**：爆款分是同批排序器不是预言机；冷启动无数据时别承诺效果。
6. **开源协议**：hotclip AGPL-3.0 传染性强，商用闭源集成需法务评估；FunClip/AutoClip MIT 友好。
7. **录制协议风险**：抖音签名逆向（a_bogus）Cookie 24h 过期、平台风控，录制模块维护成本高——MVP 阶段建议先做「本地文件/回放 URL」输入，绕开录制。
