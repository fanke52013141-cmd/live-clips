# AutoClip 设计系统 — Krepling 编辑风（Editorial Minimal）

来源：krepling.com 实拍截图分析。核心气质：克制、留白、编辑感排版。黑白为骨、淡紫为魂、粉紫渐变为点缀。替代 AntD 默认工程师皮肤，做成 Apple 式品牌感界面。

## 配色

- 页面底色：暖白 `#FAFAF8`；卡片：纯白 `#FFFFFF`
- 墨色：标题/反转区块近黑 `#0A0A0A`；正文 `#3F3F46`；次要文本 `#71717A`
- 主色（accent）：淡紫 `#8B5CF6`，hover `#7C3AED`；浅紫面 `#EDE9FE`；淡紫描边 `#C4B5FD`
- 点缀渐变：粉→紫柔和渐变 `#FCD9C8 → #C9B8F5 → #DDD6FE`，只用于 hero 媒体区与空状态插画底
- 状态：成功 `#16A34A`、警告 `#D97706`、错误 `#DC2626`（低饱和，仅色点与提示条）
- 分隔线：`#E7E5E4`（1px，弱化）

## 字体

- 全局 Inter；中文回退 PingFang SC / Microsoft YaHei
- Display 标题：28-44px，weight 620，letter-spacing -0.02em，近黑
- 区块标题 H2：22-26px，weight 600
- 正文 15px / 1.6；辅助 13px `#71717A`
- 数字与进度用 tabular-nums

## 布局与间距

- 内容最大宽 1120px 居中；页面左右 padding 32px
- 间距节奏（8 的倍数）：卡片内 24px，卡片间 24px，区块间 64-96px（宁大勿小）
- 顶部导航高 72px：左 logo，中导航，右「次要文字按钮 + 主 CTA」

## 形状与组件

- 圆角：卡片 20px；输入框 12px；按钮 pill（全圆角）
- 卡片：白底 + `#E7E5E4` 1px 描边 + 极浅阴影（0 1px 2px rgba(0,0,0,.04)）；无重投影
- 反转卡：黑底 `#0A0A0A` 白字，用于强调区块（一键出片主操作区）
- 按钮：主=黑底白字 pill；次=白底 1px 紫描边 pill；幽灵=纯文字
- 输入框/选择器：白底 1px `#D4D4D8`；focus 紫描边 + 2px 浅紫外圈
- 进度条：高 6px 圆角，轨道 `#EDE9FE`，填充紫渐变
- 状态：色点+文本（不用大色块）；表格行 hover `#FAFAF8`
- 空状态：粉紫渐变圆角底 + 简洁插画 + 单行引导 + pill CTA
- 锚点导航：页面右侧浮动小 pill 菜单（Krepling 特色），用于长页面分区跳转；选中项用浅紫底 `#EDE9FE` 高亮，不带左侧指示点/色条
- **选中态规范**：一律用「整卡 1px 紫描边 `#8B5CF6`（或浅紫描边 `#C4B5FD`）+ 极浅紫底 `#EDE9FE`」表达；**严禁任何形式的左侧彩色竖条 / 左边框着色**（`border-l-*` 色条、绝对定位色条、`::before` 左侧指示条均不允许）

## 禁止

**左侧彩色边条 / 左边框着色（所有页面、所有组件，零容忍）**；大面积高饱和渐变背景；粗重投影；默认蓝链接色；表格斑马纹；密集小字号。

## 应用于

AutoClip 桌面/Web 界面五个核心页面：① 首页项目列表 ② 链接导入页 ③ 项目详情（候选切片+进度）④ 设置页 ⑤ 审阅/渲染页。
